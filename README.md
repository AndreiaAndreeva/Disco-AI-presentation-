# Выгрузка по заданию «Почему снизилась конверсия»

Пакет лежит рядом с исходными данными: `data/deliverables/`.

## Состав

| Файл | Что внутри |
|---|---|
| `memo.md` | Записка руководителю, 199 слов |
| `memo_detailed.md` | Детальная записка: контекст, данные, локализация, альтернативы, гипотеза, план, что делать дальше и приложение с расчётом |
| `report.md` | Полный анализ: проверка данных, периоды, разложение, сегменты, динамика, альтернативы, допущения |
| `calculation.md` | Пошаговый разбор расчёта: формулы, промежуточные числа, инварианты |
| `agent_prompt.md` | Системный промпт агента под MCP-инструменты |
| `agent_requests.md` | Ключевые запросы к агенту, включая MCP-прогон |
| `data_dictionary.md` | Словарь данных |
| `charts/` | 5 графиков из анализа |
| `tools/` | MCP-сервер, клиент, набор инструментов, схемы `tools.json`, лаунчер диалога |
| `logs/run_all.log` | Лог последнего прогона |

## Воспроизведение

Из корня проекта (где лежит папка `data/`):

```bash
MPLCONFIGDIR=.mplconfig python3 analysis/analyze.py    # таблицы и графики
MPLCONFIGDIR=.mplconfig python3 -m funnel_tools.run --all   # шаги 1–6 с печатью расчёта
python3 -m funnel_tools.mcp_server                      # MCP-сервер (stdio)
python3 -m funnel_tools.mcp_client --run-all            # вызовы через MCP
```

Диалог с агентом:

```bash
bash start.sh --key-file ~/Downloads/homework/.env
```

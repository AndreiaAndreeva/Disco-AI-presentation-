## 2. Что перепроверено в расчётах агента

Аудит шёл независимыми пересчётами, а не повторным запуском того же кода:

| Проверка | Как проверяли | Результат |
|---|---|---|
| Сумма сегментов = итог | сложили `bookings_completed` и `visitors` по 8 строкам платформ × регионов за каждый период и сверили с общей воронкой | совпадает до человека |
| Конверсия не «среднее средних» | сравнили пулинг счётчиков и среднее недельных конверсий | расхождение < 0,05 п.п. |
| Дубль не влияет на вывод | пересчитали текущий период с дублем и без | 0,06 п.п. |
| Границы периодов не режут недели | сверили `week_start` + 6 дней с датами словаря | 05.10 = 5–11.10, 12.10 и 19.10 целиком в текущем |
| Вклады в Δ суммируются | сумма вкладов платформ = −3,10 −0,10 −0,02 +0,04 = −3,18 = факт | сходится |
| z-тест не врёт | пересчитали вручную для слот → форма: по mobile_web и по всем платформам | mobile_web z ≈ −37,6; все платформы z ≈ −20,9; p < 0,001 в обоих случаях |
| Дата начала эффекта | пересчитали ожидание при старте 17.10 вручную (5/7 и 2/7) | 62,1% против 44,2% — расхождение реальное |
| Потерянные записи | пересчитали контрфакт: 0,2899 × 15 826 − 2 957 | 1 631 |
| Графики не противоречат таблицам | сверили точки на графиках с `weekly_by_platform.csv` | совпадают |

Найденные ошибки первого прохода, которые пришлось исправить:

1. **Агрегация до дедупликации** — первый прогон считал итоги по 169 строкам, включая дубль; заменено на 168.
2. **Смешение уровней** — этапная конверсия «слот → форма» сначала считалась по всем платформам (69,04% → 61,78%), а рядом стояла mobile_web (69,06% → 44,50%). В отчёте эти два числа теперь явно разделены.
3. **Неверная датировка** — первая версия привязала перелом к 17.10 по журналу; проверка показала, что эффект присутствует всю неделю 12.10. Гипотеза переформулирована, расхождение вынесено в отчёт.
4. **Подпись графика** перекрывала линию mobile_web; перенесена в свободную область.

## 3. Воспроизводимость

```bash
MPLCONFIGDIR=.mplconfig python3 analysis/analyze.py
```

Скрипт читает `data/funnel_weekly_raw.csv` и `data/change_log.csv`, пишет
`analysis/tables/*.csv` и `analysis/charts/*.png`, печатает все числа из отчёта
в stdout. Внешних зависимостей, кроме pandas, numpy и matplotlib, нет.

Аудит исходного инструмента (`funnel_tool.py` + промпт агента) — в `AGENT_AUDIT.md`;
там же разбор 12 дефектов, сравнение выдачи инструмента с корректными числами и
записка в задуманном шаблоне (`MEMO_AGENT_FORMAT.md`).
